# 医院を駅ごとに追加する手順

Claude の API を使わずに医院を増やすための手順です。毎日の予定タスク（Claude Code）がこの手順で 10 院ずつ調べ、`lib/real-clinics.ts` に足して PR を作ります。PR をマージすると Vercel が自動でデプロイし、サイトに載ります。

## どの駅を調べるか
- `lib/yamanote.ts` の `STATION_PRIORITY` の順（渋谷 → 新宿 → 池袋 → 恵比寿 → 原宿 → 高田馬場 → …）。
- 1駅 20 院（`PER_STATION_TARGET`）たまるか、条件に合う医院が見つからなくなったら次の駅へ。
- 1回に追加するのは 10 院まで。

## 載せてよい医院
- 対象の山手線の駅から徒歩 10 分以内（公式サイトのアクセス記載で判断）。
- ホワイトニング（`whitening_*`）か矯正（`ortho_*`）の料金を**公式サイトで**確認できる歯科医院。
- すでに載っている医院（名前・公式サイトのドメインが同じ）は除く。

## 書いてよい情報
- 公式サイトに書かれている医院名・所在地・料金・期間だけ。料金ごとに、確認したページの URL を `source_url` に入れる。
- 税込と明記されていない料金は `NO_TAX` を `price_note` に入れる。検査料・調整料・保定装置が別なら、その旨と金額を `price_note` に書く。
- `catch_copy` は公式サイトの事実だけを短く（「駅徒歩1分」「土日診療」など）。「日本一」「必ず」「痛くない」などの誇大・比較表現、口コミ・評価・症例写真・認定医の記載は書かない（医療広告ガイドライン）。
- Google の評価や口コミ件数は使わない。

## 書き方
- `lib/real-clinics.ts` で駅ごとのヘルパーを作る：`const shinjuku = at("shinjuku", "新宿駅", "新宿区", "2026-10-30");`
- `id` は `id(n)` で、既存の最大の番号の続き。`slug` は英小文字とハイフンで、既存と重ならないもの。
- `option_code` は `lib/types.ts` の `TreatmentOption` から選ぶ。
- 追加したら `npx tsc --noEmit` と `npx next build` が通ることを確認する。
